# 行为树可视化编辑器

## 功能特性

这是一个为 Dota 2 自定义游戏开发的可视化行为树编辑器,支持编辑 `.tree` 文件(实际为 KV 格式)。

### 主要功能

- ✅ **可视化编辑**: 以图形化方式展示和编辑行为树
- ✅ **拖拽支持**: 鼠标拖动节点调整位置
- ✅ **节点操作**: 添加、删除、编辑节点
- ✅ **自动布局**: 自动排列节点位置
- ✅ **实时保存**: 保存后自动更新 KV 文件
- ✅ **缩放平移**: 支持画布缩放和平移操作

## 支持的节点类型

| 节点类型 | 图标 | 颜色 | 说明 |
|---------|------|------|------|
| Root | 🌳 | 紫色 | 根节点,行为树入口 |
| Sequence | ➡️ | 蓝色 | 序列节点,按顺序执行所有子节点 |
| Selector | ❓ | 橙色 | 选择器节点,选择第一个成功的子节点 |
| Parallel | ⚡ | 绿色 | 并行节点,同时执行所有子节点 |
| Condition | 🔍 | 青色 | 条件节点,判断条件是否满足 |
| Action | ⚙️ | 红色 | 动作节点,执行具体动作 |
| Decorator | 🎨 | 粉色 | 装饰器节点,修饰子节点行为 |

## 使用方法

### 1. 打开文件

- 双击 `.tree` 文件,会自动使用行为树编辑器打开
- 或右键点击文件,选择 "打开方式" > "Behavior Tree Editor"

### 2. 查看节点

- **双击节点**: 在右侧属性面板中显示节点详情
- **悬停节点**: 节点会高亮显示

### 3. 编辑节点

1. 双击选中节点,在右侧属性面板中编辑:
   - 修改节点类型
   - 修改节点名称
   - 修改节点描述
   - 修改自定义属性

2. 拖动节点调整位置

### 4. 添加节点

1. 双击选择父节点(或直接点击工具栏的"添加节点"按钮)
2. 点击工具栏的"➕ 添加节点"按钮
3. 在对话框中输入:
   - 选择节点类型
   - 输入节点名称
   - 输入描述(可选)
4. 点击"添加"完成

### 5. 删除节点

1. 双击选中要删除的节点
2. 点击工具栏的"🗑️ 删除"按钮,或按 `Delete` 键
3. 注意:根节点无法删除

### 6. 保存

- 点击工具栏的"💾 保存"按钮
- 或按快捷键 `Ctrl+S`

### 7. 视图操作

- **平移画布**: 鼠标拖动空白区域
- **缩放**: 鼠标滚轮
- **放大**: 点击 "🔍+" 按钮
- **缩小**: 点击 "🔍-" 按钮
- **适应画布**: 点击 "⛶ 适应" 按钮,自动调整缩放和位置

## 文件格式

`.tree` 文件使用标准的 Dota 2 KV 格式:

```
"BehaviorTree"
{
    "Type"          "Root"
    "Name"          "AI行为树"
    "Description"   "示例行为树"
    "Children"
    {
        "MainSequence"
        {
            "Type"          "Sequence"
            "Name"          "主序列"
            "Description"   "按顺序执行所有子节点"
            "Children"
            {
                "CheckHealth"
                {
                    "Type"          "Condition"
                    "Name"          "检查生命值"
                    "Description"   "判断生命值是否低于50%"
                }
                ...
            }
        }
    }
}
```

### 节点属性

每个节点必须包含:
- `Type`: 节点类型 (Root/Sequence/Selector/Parallel/Condition/Action/Decorator)
- `Name`: 节点名称

可选属性:
- `Description`: 节点描述
- `Children`: 子节点列表
- `X`, `Y`: 节点位置(自动保存)
- 其他自定义属性

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 保存文件 |
| `Delete` | 删除选中节点 |
| `双击节点` | 选中并显示属性 |
| `鼠标滚轮` | 缩放画布 |

## 注意事项

1. **文件编码**: 使用 UTF-8 编码保存文件
2. **节点名称**: 避免使用特殊字符和空格作为键名
3. **备份**: 建议使用版本控制系统(如 Git)管理行为树文件
4. **性能**: 大型行为树(超过100个节点)可能影响编辑器性能

## 技术实现

- **前端**: HTML5 Canvas + 原生 JavaScript
- **后端**: TypeScript + VS Code Extension API
- **文件格式**: Dota 2 KV (KeyValue) 格式
- **解析器**: 使用项目现有的 `kvUtils.ts` 工具
