# KV 编辑器多行复制粘贴功能

## 功能说明

KV 编辑器现在支持对行进行快速复制粘贴，并且支持一次选中多行进行批量操作。

## 使用方法

### 1. 选择行

有三种方式选择行：

- **单选**：直接点击行号（最左侧的数字列）
- **多选**：按住 `Ctrl`（或 macOS 上的 `Cmd`）同时点击行号，可以选择多个不连续的行
- **范围选择**：先选择一行，然后按住 `Shift` 点击另一行，会选中两行之间的所有行

### 2. 复制行

选中一行或多行后，按 `Ctrl + C`（或 macOS 上的 `Cmd + C`）复制选中的行。

**注意**：
- 行复制和单元格复制是独立的两个功能
- 当你选中行号时，复制操作会复制整行数据
- 当你选中单元格时，复制操作只会复制单元格内容

### 3. 粘贴行

复制行后，按 `Ctrl + V`（或 macOS 上的 `Cmd + V`）粘贴。

**粘贴行为**：
- 如果有选中的行，新行会插入到最后一个选中行的后面
- 如果没有选中行，新行会插入到表格末尾
- 粘贴的行会自动生成新的唯一 ID
- 所有字段数据都会被复制，包括嵌套的 `AbilitySpecial` 和 `Creature` 字段

### 4. 清除选择

按 `Escape` 键可以清除所有行选择。

## 视觉反馈

- 选中的行会显示浅蓝色背景高亮
- 复制/粘贴操作成功后，会在右下角显示临时提示消息（如 "已复制 3 行"）
- 提示消息会在 1 秒后自动消失

## 技术细节

### 前端实现（webview/KvEditor/KvEditor.js）

- `selectedRows` Set - 存储选中的行索引
- `lastSelectedRowIndex` - 用于 Shift 范围选择
- `copiedRowsData` - 存储复制的行数据
- `toggleRowSelection()` - 处理行选择逻辑
- `copySelectedRows()` - 复制选中行的数据
- `pasteRows()` - 发送粘贴请求到后端

### 后端实现（src/CustomTextEditorProvider/kvEditorProvider.ts）

- `handleBulkInsertRows()` - 批量插入行的方法
- `KvEditorBulkInsertRowsMessage` - 批量插入消息接口
- 自动处理嵌套字段（AbilitySpecial、Creature）的重建
- 自动生成唯一的行 ID

### CSS 样式（webview/KvEditor/KvEditor.css）

- `.kv-row-selected` - 选中行的样式
- `@keyframes kv-message-slide-in` - 提示消息滑入动画
- `@keyframes kv-message-fade-out` - 提示消息淡出动画

## 限制和注意事项

1. **行选择与单元格选择互斥**：点击行号进入行选择模式，会自动清除单元格选择；点击其他单元格会进入单元格编辑模式
2. **点击行号即选中**：无需按任何键，直接点击行号即可选中该行；按住 Ctrl/Shift 可进行多选
3. **数据完整性**：粘贴时会深拷贝所有数据，确保不会影响原始数据
4. **ID 自动生成**：粘贴的行会获得新的唯一 ID，避免冲突
5. **拖动按钮位置**：注意区分行号数字和左侧的拖动按钮（gripper 图标），应该点击数字部分

## 已知问题修复（2025-11-05）

### 修复的 Bug
1. ✅ **点击行号不高亮**: 原逻辑要求按 Ctrl 才选中，已改为直接点击即选中
2. ✅ **Ctrl+C 无提示**: 修复了事件处理顺序和条件判断，现在正确显示提示
3. ✅ **Ctrl+V 无效**: 修复了粘贴条件判断，允许在任意状态下粘贴已复制的数据

### 技术改进
- 行复制粘贴事件监听器优先于单元格处理
- `toggleRowSelection()` 自动清除单元格选择状态
- 简化点击行号的逻辑，移除不必要的条件判断
- 改进快捷键处理，分离复制和粘贴的前置条件检查
