# 行为树编辑器 - Params 参数功能

## 功能概述

行为树编辑器现在支持为节点添加、编辑和删除 Params 参数。这个功能允许你为行为树节点配置自定义参数。

## 如何使用

### 1. 查看参数

当你选择一个包含 Params 的节点时，属性面板会显示一个"参数 (Params)"部分，列出所有现有参数。

### 2. 添加参数

1. 在属性面板中找到"参数 (Params)"部分
2. 点击"➕ 添加参数"按钮
3. 系统会自动创建一个名为 `NewParam` 的新参数（如果已存在则为 `NewParam1`, `NewParam2` 等）
4. 在参数名输入框中输入参数名称
5. 在参数值输入框中输入参数值

### 3. 编辑参数

- **修改参数名**：直接在参数名输入框中编辑，失焦后自动保存
- **修改参数值**：直接在参数值输入框中编辑，实时保存

### 4. 删除参数

点击参数右侧的垃圾桶图标 (🗑️) 即可删除该参数。

## 示例

以下是一个包含 Params 的节点示例：

```
"CheckHealth"
{
    "Type"          "Condition"
    "Name"          "检查生命值"
    "Description"   "判断生命值是否低于50%"
    "Threshold"     "1"
    "Params"
    {
        "HealthPercent"   "50"
        "CheckInterval"   "1.0"
    }
}
```

在编辑器中：
- `HealthPercent` 参数可以配置生命值百分比阈值
- `CheckInterval` 参数可以配置检查间隔时间

## 技术说明

### 数据格式

Params 以嵌套对象的形式存储在节点数据中：

```typescript
{
    "Params": {
        "参数名1": "参数值1",
        "参数名2": "参数值2"
    }
}
```

### 兼容性

- 支持 `Params`（大写 P）和 `params`（小写 p）两种命名
- 如果节点没有 Params，首次添加参数会自动创建 `Params` 字段
- 删除所有参数后，Params 对象会被移除

### 保存和加载

- 所有 Params 参数会随着行为树文件自动保存
- 重新打开文件时，参数会被正确加载和显示
- 使用 Ctrl+S 或点击保存按钮保存更改

## 界面说明

参数编辑区域包含：
- **参数名输入框**：左侧较窄的输入框，用于输入参数名称
- **参数值输入框**：中间较宽的输入框，用于输入参数值
- **删除按钮**：右侧的垃圾桶图标，用于删除参数

## 快捷操作

- 添加参数后，参数名输入框会自动获得焦点
- 修改参数名后按回车键可以快速跳到下一个输入框
- 使用 Tab 键在输入框之间导航

## 注意事项

1. 参数名不能为空，否则可能导致数据丢失
2. 参数名应该使用有意义的英文标识符
3. 参数值为字符串类型，在实际使用时需要转换为相应类型
4. 删除参数后无法撤销，请谨慎操作
